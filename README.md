One joke about cats, a single line under 200 characters.

> "The cat walked across my keyboard and typed a better email than I ever have. HR replied."

`main.ts` (Node 22, stdlib only) writes exactly that line to `/output/entry.txt`.
See [METHOD.md](METHOD.md) for the 30-candidate tournament that picked it.
